# 配色规范 v4 —— 软萌手账版

> 对应设计稿：《校园分享小程序-高保真交互稿-v4软萌手账风》（Ardot fileId 739654946579466，9 画板）
> 代码落点：`miniprogram/theme.wxss`（变量全量替换，变量名与 v3 保持一致）、`miniprogram/app.json`
> v3（青绿 #0B7F6C 体系）已废弃，`docs/配色规范-v3.md` 仅作历史参考

## 1. 设计原则

- 整体像一本可爱的手账 App：淡紫到淡蓝的柔和渐变底、纯白大圆角卡片、糖果色小贴纸
- 留白多，无深色块、无锐利直角、无密集线条；淡紫只用于装饰，不用于正文承载
- 正文对比度 ≥ 4.5:1（WCAG AA）；图标/装饰 ≥ 3:1

## 2. 背景与卡片

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面渐变 | `#F5F1FF → #EAF4FF`（180°） | `app.wxss` 的 `page` 上实现，实底回退 `--bg-page: #F5F1FF` |
| 卡片 | `#FFFFFF` | 圆角 24px（48rpx），**无描边** |
| 卡片阴影 | `0 16rpx 48rpx rgba(108,92,231,.08)` | 紫晕阴影，全站统一 |
| 输入框/分区底 | `#F7F4FF` | `--bg-subtle` / `--bg-muted` |

## 3. 主色：紫罗兰

| 变量 | 色值 | 用途 | 对比度 |
|---|---|---|---|
| `--brand-100` | `#EDE9FE` | 淡紫底（标签、AI 私密卡、图标底） | — |
| `--brand-700` | **`#6C5CE7`** | **★按钮底、主色文字、Tab 选中、选中 Chip** | 白字 4.85:1 ／ 白底 4.85:1 |
| `--brand-800` | **`#5A47C9`** | **★淡紫底上的紫色文字、链接、hover** | 淡紫底 5.6:1 |
| `--brand-900` | `#4A3AAE` | active / pressed | — |

⚠️ **`#6C5CE7` 直接放在 `#EDE9FE` 上只有 4.07:1**，不达标——淡紫底上的文字一律用 `--brand-800`（`--brand-text-soft` 为其语义别名）。

## 4. 糖果色（贴纸 / 头像 / 板块）

| 名称 | 主色 | 浅底 | 文字（深色） |
|---|---|---|---|
| 薄荷 mint | `#4ECDC4` | `#E3F7F5` | `#0E6E63` |
| 珊瑚粉 coral | `#FF7A8A` | `#FFECEF` | `#B5445C` |
| 奶黄 sun | `#FFC85C` | `#FFF3D9` | `#7A4A00` |
| 天蓝 sky | `#5AA9FF` | `#E7F1FF` | `#1B5FBF` |

- 分类贴纸：48×48px、圆角 16px，四色分配 宿舍好物=薄荷／食堂美食=珊瑚／学习资料=奶黄／选课经验=天蓝
- **匿名头像轮换**：`--avatar-1..5` = 紫/薄荷/珊瑚/奶黄/天蓝，白色"匿"字；用户可上传自定义照片头像，随时可换回默认
- 板块色映射：生活=薄荷、学习=天蓝、美食=珊瑚（`--board-*`）

## 5. 文字

| 层级 | 色值 | 对比度（白底） |
|---|---|---|
| 主文字 `--text-1` | `#2E2A3B` | ≈13:1 |
| 次文字 `--text-2` | `#6B6780` | ≈5.4:1 |
| 三级 `--text-3` | `#716D82` | ≈4.6:1 |
| 禁用 `--text-disabled` | `#A9A4B8` | 仅装饰 |

标题字体：圆体（站酷快乐体风格，落地用 `wx.loadFontFace` 子集化加载）；正文 PingFang SC。标题 20–22px，正文 15px，说明 12px。

## 6. 状态色

| 语义 | 底 | 主色 | 文字 |
|---|---|---|---|
| 成功 | `#E3F7F5` | `#0FA37F` | `#0E6E63` |
| 警告（审核中/过期） | `#FFF3D9` | `#FFB937` | `#7A4A00` |
| 错误（拦截/失败） | `#FFECEF` | `#F2606F` | `#C73648` |
| 信息（AI 提示） | `#EDE9FE` | — | `#5A47C9` |

退出登录等危险文字：`#C73648`（v4 设计稿定稿值）。

## 7. 形状

| 元素 | 圆角 |
|---|---|
| 卡片 | 24px（48rpx） |
| 图片 | 16px（32rpx） |
| 按钮 | 胶囊（999） |
| 输入框 | 16px（32rpx） |
| Chip/标签 | 胶囊 / 16rpx |
| 分类贴纸 | 48×48px、圆角 16px |

## 8. 落地核对清单

- `miniprogram/theme.wxss`：v4 变量全量（本文件第 2–7 节）
- `miniprogram/app.json`：导航栏 `#F5F1FF` + 黑字；Tab 未选中 `#6B6780`、选中 `#5A47C9`
- `miniprogram/app.wxss`：page 渐变底、`.card` 无描边、`.badge-expired` 胶囊
- 页面 wxss 无硬编码色值（仅 `#fff` 白字，随底色语义保留）
- `design/mockups.html` 为 v3 时代产物，未随 v4 更新（历史参考）
