# 可直接粘贴给 AI 设计工具的提示词（复制即用）

> 用法：全文都在代码块里，**只复制代码块内容**，不要复制表格和说明文字。
> 提示词 A：一次生成整套 7 屏；提示词 B：逐屏生成（风格更稳，推荐）。

---

## 提示词 A · 一次生成整套（7 屏）

```
你是一名擅长"新中式手账"风格的 UI 设计师。为一个校园好物分享微信小程序设计全套高保真界面，
一次输出 7 个画板，每个画板 375×812。

风格：像一本干净的手绘校园手账。宣纸暖底、墨色文字、朱砂印章、克制的手作感排版。
温和、可信、留白充分。不要做成文旅宣传页，不要景区海报式构图，不要密集插画，
不要大面积渐变、不要玻璃拟态、不要金色描边、不要卡通人物大插画。

画布与安全区：375×812，1x。状态栏 44、导航栏 44、Tab 栏 49 + 底部安全区 34。
页面左右边距 16，内容宽 343，4pt 网格。

配色（严格使用，不新增）：
页面底 #FBF6EC；卡片 #FFFDF8；描边 #EFE3CE；墨色主文字 #2B2620；次文字 #7C7266；
淡文字与占位 #B3A794；黛绿主色 #2F5D50（浅底 #E7EEE9）；朱砂强调 #B5432F（浅底 #F8E7E0）；
藤黄点缀 #C99A3E。板块色：生活=藤黄、学习=黛绿、美食=朱砂，只用于标签与板块页头，不做整块背景。

字体：标题用思源宋体 Source Han Serif SC SemiBold；正文与控件用 PingFang SC；数字用 SF Pro Text。
字阶：Display 24/32、H1 20/28、H2 17/24（标题均宋体）；正文 15/24、辅助 14/22、说明 12/18、微字 11/16。

形状：卡片圆角 14 且带 1px #EFE3CE 描边；图片圆角 10；输入框圆角 8；按钮圆角 8；Chip 圆角 6；
分类入口为 40×40 圆形。几乎不用阴影，仅搜索框与悬浮按钮用 0 4 16 rgba(43,38,32,0.06)。

图标：只用 1.5px 线性细线图标（返回、搜索、点赞、收藏、评论、举报、箭头、发送），
20×20，圆头端点，颜色 #2B2620 或 #7C7266，风格统一。允许保留的唯一装饰图形是朱砂印章
（圆形 40×40 或方形 36×36，白字宋体，边缘轻微不规则）。

照片优先原则（重要）：所有画面素材必须是真实校园照片风格——食堂菜品与窗口、宿舍桌面、
图书馆与书本笔记、教学楼走廊。不得出现手绘插画、矢量风景画、卡通图形。
页头 banner、板块页头、分类入口、空态底图全部用照片（分类入口用圆形照片裁切）。
照片上叠文字时加 20%~35% 墨色渐变蒙版保证可读性，不加彩色滤镜。
内容卡片内部的照片保持原样：无滤镜、无叠字、无边框。

7 个画板依次如下：

1) 首页：顶部 375×140 校园实拍照片页头，右侧叠 30% 墨色渐变，左上两行白色宋体标语
"把好东西，留在这所学校"23px，右上角 36px 朱砂方印"校园分享"。页头下方叠压一个 343×40
圆角搜索框（上浮 20px，白底细描边，占位"搜好物 / 美食 / 资料…"）。其下横排 4 个分类入口：
40×40 圆形校园照片 + 11px 灰字（生活好物／食堂美食／学习资料／选课经验）。再下 343×64 浅朱底
圆角条，左 40 朱砂圆印"AI"，文案"问问同学都在推荐什么"，右箭头。主体为单列照片卡片流 3 张：
3:2 大图圆角 10 → 宋体标题 17 两行 → 灰色摘要 14 两行 → 底部"匿名 · 3 天前"与收藏点赞数。
右下角 52px 圆形黛绿发帖按钮。底部三 Tab：首页／问答／我的。

2) 板块页（美食）：导航返回 + 宋体"美食"。下方 343×96 页头，用食堂窗口真实照片，圆角 14，
右侧 30% 墨色渐变，左下白色宋体"美食"与"共 42 条"。页头下一行 11px 灰字
"板块内容均为同学个人体验分享"。主体单列照片卡片流，其中一张右上角带半透明"可能已过期"角标。
右下角黛绿圆形发帖按钮。

3) 发帖页：导航左"取消"、中宋体"发帖"、右黛绿"发布"。三个圆角方块 Chip（生活／学习／美食，
美食为朱砂实底白字）。无边框宋体大标题输入（占位"一句话概括（选填）"），多行正文输入
（占位"说说你的真实体验～"，高 160，右下角"0/2000"）。3 列图片网格：两张 100×100 照片缩略图
（右上半透明删除）+ 一个虚线加号格。"补充信息（选填）"小节 + 三个米色输入框（店名/窗口、人均、位置）。
底部两行 11px 提示"前台统一显示匿名""请描述亲身经历，不要做无依据的猜测或指控"。

4) 详情页：顶部 375×281 全宽 4:3 照片，底部三枚分页圆点。图下左右 16：朱砂浅底"美食"标签 →
宋体 20px 两行标题 → "匿名 · 2 天前"12px 灰 → 正文 15px 1.7 行距 → 横排米色小标签
（¥8／一食堂二楼／2026.09）→ 浅绿私密卡"你的分享被 AI 引用了 12 次，帮到 12 位同学"
→ 评论标题与两条评论（32px 圆形"匿"字头像、匿名 #3、内容、时间）。底部固定操作条：
左评论输入框，右点赞/收藏/举报图标与计数。

5) AI 问答页：导航宋体"AI 问答"，其下 11px 灰字"仅基于本校同学的分享回答"。对话区：
AI 白卡气泡（圆角 16，左上小圆角，细描边）+ 用户右对齐黛绿气泡"食堂哪家麻辣烫好吃？"
+ AI 回答气泡下挂 2 张引用帖卡片（56 缩略图 + 标题 + 匿名·时间 + 箭头）。底部圆角输入框
+ 36px 圆形黛绿发送按钮，下方 11px 淡灰"内容由 AI 生成，仅供参考"。

6) 我的：64px 圆形"匿"字头像（浅绿底黛绿字）+ 宋体"匿名同学" + 11px 灰"你的身份仅自己可见"。
白色数据卡三列（我的分享 12／收藏 8／被引用 34，数字 20 宋体，标签 11 灰，1px 竖向分割）。
白卡菜单四项（我的分享、我的收藏、站内消息带朱砂小红点、关于带版本号），右箭头；
末行"审核台"带朱砂小方章"3"。底部居中朱砂文字按钮"退出登录"。

7) 审核后台：导航"审核台" + 右侧刷新图标。三个 Tab（待审 3 选中／举报 1／已处理），
选中项墨色 15 + 下方 24px 宽 2px 黛绿短横。主体两张审核卡：白卡细描边圆角 14，顶行
"美食"标签 + "AI 判定：疑似指控"浅朱底小标签 + 右侧时间，中间三行内容摘要，
底部左"驳回"描边按钮、右"通过"黛绿实底按钮（各 120×36 圆角 8）。第二张卡多一行举报理由。
工具感、冷静、不用插画。

每个画板配一个浅色标注说明屏名。整体留白充分，层级靠字重与留白区分而非颜色。
```

## 补充 · 状态变体提示词（同一画板内出变体时用）

```
基于同一风格，额外输出以下状态变体（每个 375×812）：
1. 首页空态：淡化校园照片压暗至 20% 作底 + "还没有内容" + "来发第一条，帮到下一个同学"
   + 黛绿主按钮"发布第一条分享"。
2. 板块空态：空食堂照片压暗 + "这个板块还空着" + 黛绿按钮"发布美食分享"。
3. 发帖上传中：某张缩略图覆盖 60% 白色遮罩 + 环形加载指示。
4. 详情已点赞：点赞图标填充黛绿、计数由 12 变 13。
5. 详情举报弹层：底部弹层圆角 16 16 0 0，四条理由单选 + 黛绿主按钮"提交举报"
   + 下方 11px 灰字"我们会在 48 小时内处理"，背景遮罩 rgba(43,38,32,0.35)。
6. AI 思考中：AI 气泡内三个 6px 灰点依次跳动 + "正在翻同学们的分享…"。
7. AI 无结果：AI 气泡说明站内暂无相关分享 + 内嵌黛绿按钮"去发一条"。
8. 审核已清空：居中文案"今日已清空" + "下次集中处理：明天 10:00"。
```

## 使用建议

1. 优先用**提示词 B 逐屏生成**：AI 工具一次处理 7 屏容易丢失细节，逐屏质量更高；
2. 首屏生成后，如果风格满意，后续提示词开头加一句「沿用上一屏的风格」可进一步稳定；
3. 生成后用 `docs/高保真UI设计提示词-v2-新中式.md` §6 检查清单逐项核对；
4. 本地已有一套 HTML 高保真稿可参考：`design/mockups.html`（浏览器打开，顶部可切换 15 个屏与状态）。
