## 0. 如何使用本文档

1. 先把「§1 主提示词」整段复制给 AI 设计工具，建立全局风格与设计系统；
2. 再按「§4 逐屏提示词」逐页生成，**每次只生成一个画板**，避免风格漂移；
3. 生成后按「§6 交付检查清单」逐项核对，缺失项用「§5 组件状态」补齐变体。

## §1 主提示词（系统级，先发这一段）

```
你是一名擅长东方极简主义的 UI 设计师，为一个"校园好物分享"微信小程序设计全套高保真界面。

【风格定位】
极简、轻量、有纸感。整体大量留白，照片是主角，文字克制。视觉气质参考：暖米白纸底、柔和圆角卡片、
手绘感细线小图标、克制的暖橙点缀。禁止出现：密集插画、大面积渐变、国潮纹样堆叠、金色描边、
多彩色块拼接、景区海报式构图。目标是"像一本干净的校园手账"，不是"文旅宣传页"。

【画布与安全区】
- 画布：375 × 812 px，1x 设计稿
- 状态栏 44px｜导航栏 44px｜Tab 栏 49px + 底部安全区 34px
- 页面左右边距统一 16px，内容宽度 343px

【色彩（严格使用，不得新增）】
- 页面底色：#FAF7F2（暖米白，纸感）
- 卡片/浮层：#FFFFFF
- 主文字：#1E1C19
- 次文字：#7A756D
- 三级文字/占位：#B5AFA5
- 分割线：#EFE9E0
- 品牌主色（松墨绿）：#3B6B57；浅色底：#E8F0EB
- 强调色（暖陶橙，仅用于 AI 入口与关键 CTA）：#E07B4C；浅色底：#FBEDE4
- 警示/印章红（仅极小面积点缀）：#B4432F
- 板块色：生活 #C08A2E ｜ 学习 #3B6B57 ｜ 美食 #E07B4C（均以 10% 透明度作标签底色）

【字体】
- 中文：PingFang SC；数字与英文：SF Pro Text（表格数字等宽）
- 字阶（字号/行高，字重）：
  - Display 24/32 SemiBold（仅首页大标题）
  - H1 20/28 Semibold（详情页标题）
  - H2 17/24 Semibold（卡片标题、导航标题）
  - Body 15/24 Regular（正文）
  - Body-S 14/22 Regular（评论、表单）
  - Caption 12/18 Regular（元信息、标签）
  - Micro 11/16 Regular（时间戳、声明、AI 提示）

【间距与圆角】
- 4pt 基准网格；页面边距 16；卡片内边距 16；卡片间距 12；组内元素间距 8
- 圆角：卡片 12｜图片 10｜输入框 10｜主按钮 12｜Chip 999（全圆）｜头像 50%
- 阴影：卡片 0 2 8 rgba(30,28,25,0.04)；悬浮按钮 0 6 20 rgba(59,107,87,0.24)
- 描边：仅用于未选中 Chip 与输入框，1px #EFE9E0

【图标】
- 线性图标，1.5px 描边，圆头端点，20×20（导航与 Tab 为 24×24），单色（#1E1C19 或 #7A756D）
- 允许轻微手绘不规则的笔触感，但同一套图标必须风格统一
- 板块图标可用"双色填充小手绘"（生活=小台灯、学习=书本、美食=碗筷），仅出现在 Chip 与板块页标题旁，尺寸 20×20

【图片规范】
- 信息流卡片图：343 × 229（3:2），圆角 10，不叠加滤镜与文字
- 详情页头图：375 × 281（4:3），全宽无圆角
- 缩略图：64 × 64，圆角 8
- 占位图统一用浅米色块 #F1ECE4 + 居中细线图标，不使用灰色渐变

【通用原则】
- 一个页面最多出现 1 个强调色元素
- 每屏最多 2 种字号用于正文层级
- 所有列表项高度为 4 的倍数
- 不做拟物投影、不做玻璃拟态、不做彩色描边按钮
```

## §2 信息架构与跳转关系

```
注册页（邀请码）
   └─ 成功 → 首页（reLaunch，不可返回）

Tab 1 首页
   ├─ 搜索框 →（同页内切换为搜索结果态）
   ├─ AI 问答横幅 → Tab 2 AI 问答
   ├─ 板块 Chip：生活/学习/美食 → 板块页
   ├─ 帖子卡片 → 详情页
   └─ 悬浮按钮「发帖」→ 发帖页

Tab 2 AI 问答
   ├─ 引用帖子卡 → 详情页
   └─ 无结果 → 待发帖引导 → 发帖页

Tab 3 我的
   ├─ 我的分享 → 我的分享列表（复用信息流卡片）
   ├─ 我的收藏 → 收藏列表
   ├─ 站内消息（红点）→ 消息中心（二期，本次可只做入口 + 空态）
   └─ 退出 → 注册页

板块页
   ├─ 帖子卡片 → 详情页
   └─ 悬浮按钮「发帖」→ 发帖页（预选当前板块）

详情页
   ├─ 返回 → 上级页面
   ├─ 点赞 / 收藏（就地切换，无跳转）
   ├─ 评论（就地展开评论输入）
   ├─ 举报 → 底部弹层（选择理由）
   └─ 作者本人：显示「被 AI 引用 N 次」私密数据卡

发帖页
   ├─ 返回：有未保存内容 → 二次确认弹窗
   └─ 发布成功 → 返回上一页 + Toast；审核中 → Toast「审核通过后展示」

审核后台（仅管理员，入口隐藏在我的页最底部）
   ├─ 待审 Tab：通过 / 驳回
   ├─ 举报 Tab：处理 / 忽略
   └─ 已处理 Tab：只读
```

## §7 需要避免的三个方向（防止 AI 跑偏）

1. **不要做文旅风**：参考图是"文旅国风"，其密集插画和海报式 banner 不适合内容社区；只取它的暖米底、圆角、手绘小图标与克制配色。
2. **不要做小红书式双列瀑布流**：单校内容量撑不起双列，且双列会压缩图片信息；一律单列 3:2 大图。
3. **不要用蓝色科技感**：禁止蓝紫渐变、发光按钮、玻璃拟态，会破坏"校园手账"的信任感。
