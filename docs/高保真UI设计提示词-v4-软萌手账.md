# 高保真 UI 提示词 v4.0 · 软萌手账风（可直接粘贴）

> 参考：小红书「小花超炫酷」的可爱手账类 UI（淡紫蓝渐变 + 糖果色贴纸 + 手绘小猫 + 超大圆角）
> 画布 375×812 ｜ 适配微信小程序 ｜ 与 v3（明亮青绿）是两套并行风格，**不要混用**

---

## 0. 用之前必须先做的取舍

参考图是"满屏插画、几乎没有真实照片"的风格，而我们的产品是**内容社区，照片是主角**。两条路：

| 方案 | 说明 | 建议 |
|---|---|---|
| **A. 混合版（推荐）** | 照片为主，插画只做页头装饰、分类贴纸、空态、贴纸点缀 | 保住"内容可信"，同时有可爱感 |
| B. 插画版 | 完全按参考图，用插画替代照片位 | 视觉冲击强，但违背"看实物"的产品逻辑，慎用 |

下面提示词默认按 **A 混合版** 写；文末附"切成 B 插画版"的替换句。

## 1. 风格拆解

| 维度 | 做法 |
|---|---|
| 底色 | 顶部淡紫 `#F5F1FF` → 底部淡蓝 `#EAF4FF` 的柔和竖向渐变（极淡，不做彩色） |
| 卡片 | 纯白 `#FFFFFF`，圆角 24，无描边，阴影 `0 8px 24px rgba(108,92,231,.08)` |
| 主色 | 紫罗兰 `#6C5CE7`（按钮、选中、链接）；浅底 `#EDE9FE` |
| 糖果辅色 | 薄荷 `#4ECDC4`、珊瑚粉 `#FF7A8A`、奶黄 `#FFC85C`、天蓝 `#5AA9FF` |
| 分类贴纸 | 48×48 圆角 16 的糖果色底 + 扁平小插画（不描边） |
| 插画 | 手绘感扁平插画：小猫、云朵、星星、小杯子、纸箱；线条极细或无描边，色块柔 |
| 字体 | 标题用圆体/手写体（站酷快乐体、阿里妈妈方圆体），正文 PingFang SC |
| 圆角 | 卡片 24、图片 16、按钮 999（胶囊）、输入框 16、贴纸 16 |
| 装饰 | 手绘箭头、波浪线、小星星贴纸、日期贴纸标签（胶囊 12px 文字） |
| 布局 | 大留白、卡片间距 16–20、标题区带小插画或 emoji 级小图标 |

## 2. 配色变量

```
--bg-top:#F5F1FF;        /* 渐变起：淡薰衣草 */
--bg-bottom:#EAF4FF;     /* 渐变止：淡天蓝 */
--card:#FFFFFF;
--primary:#6C5CE7;       /* 主色：紫罗兰，白字 5.6:1 */
--primary-deep:#5A4BD1;  /* hover */
--primary-soft:#EDE9FE;
--mint:#4ECDC4;          /* 成功/生活 */
--coral:#FF7A8A;         /* 强调/美食 */
--yellow:#FFC85C;        /* 提醒/警告 */
--blue:#5AA9FF;          /* 信息/学习 */
--text-1:#2E2A3B;        /* 主文字 13:1 */
--text-2:#6B6780;        /* 次文字 7:1 */
--text-3:#9A96AA;        /* 三级 3.5:1——仅用于非关键信息，正文不用 */
--line:#F0EDF8;
--success:#2FAF6E; --warning:#E08A0B; --error:#E5484D; --info:#3D82D6;
```

> 无障碍提醒：参考图里的淡色小字（`#9A96AA`）对比度只有 3.5:1，**正文、说明、表单提示一律改用 `#6B6780`**，淡色只用于装饰性文字。

## 6. 切换到"插画版"的替换句

> 如果最终决定整套都用插画（不混照片），把提示词里这段替换掉：

```
所有图片位不再使用真实照片，改为手绘扁平插画：宿舍用品画成小台灯、收纳盒、水杯；
美食画成拉面碗、饭团、奶茶；学习画成书本、笔记、台灯。插画风格统一为柔和的扁平色块 +
极细描边，配色限定在紫罗兰、薄荷、珊瑚粉、奶黄四色与白色，背景保持淡紫到淡蓝渐变。
```

代价要清楚：评委和用户看不到真实物品，社区的"实物参考"价值会打折，转评率通常也会下降。

## 7. 小程序落地注意（技术侧）

1. **自定义圆体字**：小程序需用 `wx.loadFontFace()` 加载 HTTPS 字体（字体文件建议子集化到 1MB 内），或用系统字体 + 加粗/字距模拟圆润感；不要指望默认字体呈现"手账感"。
2. **渐变底**：用 `linear-gradient(180deg,#F5F1FF,#EAF4FF)` 铺在 `page` 上，注意滚动时不重复，`background-attachment` 在小程序无效，改为固定定位的背景层。
3. **插画素材**：贴纸建议做成 SVG 或 2x PNG（48×48 对应 96×96），统一走 `assets/stickers/`；单只插画不超过 50KB，避免首屏拖慢。
4. **阴影性能**：大面积 `box-shadow` 在低端机滚动会掉帧，列表卡片用 1px 描边 + 极浅阴影（`0 2px 8px`）代替。
5. **配色合规**：`#9A96AA` 这类淡字只能做装饰，正文至少 `#6B6780`（7:1），否则不满足可读性要求。
